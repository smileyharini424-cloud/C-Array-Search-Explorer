# C-Array-Search-Explorer
# Search an Element in an Array

## Explanation

This C program searches for a given element in an array.

It uses a linear search technique. Each element is compared with the search value until the element is found or the complete array has been checked.

## Problem Statement

Write a C program to search for an element in an array.

## Features

- Accepts array elements from the user
- Accepts a search value
- Searches using linear search
- Displays the position if the element is found
- Displays a message if the element is not found

## How It Works

1. Read the number of elements.
2. Read the array elements.
3. Read the element to search.
4. Compare the search value with each array element.
5. If a match is found, display its position.
6. If no match is found, display "Element not found".
